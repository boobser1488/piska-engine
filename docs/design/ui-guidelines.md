# Оформление редактора Piska — правила

Редактор — инструмент, а не приложение: плоский, плотный, спокойный. Ориентир — Unity 6
(тёмная тема) и Blender 4. Всё, что здесь описано, доступно в коде как токены и виджеты
`crates/engine-editor/src/theme.rs` (снаружи редактора — `engine_editor::kit::theme`) и
иконки `icons.rs` (`engine_editor::kit::icons`). **Числа и цвета в панелях не пишутся** —
только токены. Нужного токена или виджета нет — добавьте его в `theme.rs`, а не в панель.

## Что делало интерфейс «детским» (и чего больше не делаем)

| было | стало |
|---|---|
| основной текст 14 px, заголовки 18 px, полужирное имя объекта, компонента, «Assets», заголовков диалогов | текст 12.5 px, полужирный (Semibold) — только заголовки панелей / разделов и выбранная вкладка |
| строки 26 px, поля инспектора ~32 px, полосы вкладок 34 px, меню 28 px, верх окна 74 px | строки 22 px, поля 20 px, вкладки 24 px, меню 22 px, верх окна 22 + 30 px |
| X / Y / Z — красная, зелёная, синяя плашка с буквой | буква приглушённого цвета оси и тонкая цветная полоска слева в поле |
| голубоватый фон (#1e1f23), «конфетно»-синий акцент #4c8dff заливкой больших площадей (наведение в меню, Play-кнопка, 2D/3D, Auto-scroll, «All») | нейтральные серые, акцент #4772B3 только на выделении, фокусе и главной кнопке; наведение в меню — серое |
| «таблетки»: фильтры Project, EDIT / PLAYING в строке состояния, счётчики консоли | прямоугольные переключатели с радиусом 2 px; «таблетка» только у крошечных счётчиков (badge) |
| скругления 5–8 px, группы кнопок на тёмных подложках с рамкой | 2 px у контролов, 0 у панелей, 4 px у меню и окон; группы — просто стоящие рядом кнопки с разделителем 1 px |
| щели между панелями, отступы вокруг дока | панели встык, между ними линия 1 px |
| иконки-«наклейки»: залитые хаки-папки, цветные значки компонентов | монохромные контурные иконки 16 px цвета текста; цвет — только тип ассета / объекта (папка, префаб) |
| диалоги: заголовок 18 px по центру, поля 20 px, кнопки 32 px | заголовок 13 px слева, поля 12 px, кнопки 22 px |

## Палитра

Уровни фона (нейтральные, каналы R = G = B ± 1, шаг между уровнями ≤ 12):

| токен | цвет | где |
|---|---|---|
| `BG_APP` | `#181818` | под панелями, строка состояния, линия-разделитель между панелями |
| `BG_HEADER` | `#1f1f1f` | полоса вкладок, меню, панель инструментов, строки-заголовки панелей |
| `BG_PANEL` | `#262626` | содержимое панели |
| `BG_RAISED` | `#2c2c2c` | заголовки компонентов, всплывающие меню, окна, подсказки |
| `BG_FIELD` | `#353535` | кнопки и выпадающие списки |
| `BG_INSET` | `#1c1c1c` | поля ввода: текст, числа, поиск |
| `BG_HOVER` / `BG_ACTIVE` | `#3e3e3e` / `#484848` | наведение / нажатие на кнопке |
| `LINE` | `#141414` | волосяные линии: между панелями, под полосами инструментов, между строками таблиц |
| `LINE_STRONG` | `#0f0f0f` | рамки полей и кнопок |
| `LINE_SOFT` | `#303030` | светлая линия внутри поднятых поверхностей (разделители меню) |

Текст: `TEXT` `#dcdcdc` (контраст ≥ 7:1 на всех уровнях), `TEXT_MUTED` `#a0a0a0` (≥ 4.5:1;
подписи полей, пути, счётчики), `TEXT_DISABLED` `#6a6a6a`, `TEXT_STRONG` `#f2f2f2`
(текст на акценте и выбранная вкладка).

Акцент — один, `theme::accent()`, выбирается в Preferences (по умолчанию «Blue» `#4772B3`,
как у Blender; остальные варианты так же приглушены). Применение:

* `selection_fill()` — фон выбранной строки в фокусе; `selection_unfocused()` — фон
  выбранной строки, когда панель не в фокусе (серый);
* `accent_soft()` — включённый переключатель (заливка), подсветка цели перетаскивания;
* `accent()` — рамка поля в фокусе, главная кнопка (`primary_button`), полоска режима Play.

Нельзя: заливать акцентом площади больше кнопки, красить акцентом текст обычных подписей,
делать акцентным наведение (исключение — пункт меню под курсором, приглушённый).
`play_tint(1.0)` — тонировка главной панели инструментов в режиме Play.

Смысловые цвета (приглушённые): `OK` `#6aa874`, `WARN` `#d2a24c`, `ERROR` `#d65f5a`,
`INFO` `#6f9fd2`, `PREFAB` `#6ab0e0`. Оси: `AXIS_X` / `AXIS_Y` / `AXIS_Z` — стандартные
красный / зелёный / синий; в полях — только тонкой полоской и буквой.

## Шрифты

Одно семейство интерфейса (Segoe UI / Noto Sans), одно моноширинное (Cascadia Mono /
Consolas / DejaVu Sans Mono).

| токен | размер | где |
|---|---|---|
| `FONT_CAPTION` | 11.5 | подписи под иконками, счётчики, строка состояния, пути |
| `FONT_BODY` | 12.5 | всё остальное: строки, поля, меню, кнопки |
| `FONT_TITLE` | 12.5, `strong` | заголовок раздела, заголовок компонента, выбранная вкладка |
| `FONT_HEADING` | 14 | заголовок диалога (полужирный) — больше крупного текста нет |
| (числа) | `drag_value_text_style = Monospace` | все `DragValue` рисуются моноширинным — стоит в `apply()` |
| `FONT_MONO` | 12 | числа в полях, код, консоль, время в профайлере |
| `FONT_SECTION` | 10.5, `strong`, ПРОПИСНЫЕ, +0.6 px | подписи групп: `section_label` («MATERIALS», «SCENE VIEW») |

Вес: по умолчанию обычный. `theme::strong()` — только заголовки панелей / разделов /
компонентов и выбранная вкладка. Имя объекта в инспекторе, «Assets», имена в списках —
обычным весом.

## Размеры (UI scale 1.0)

Сетка отступов 4 / 8: `SP_XS 2`, `SP_S 4`, `SP_M 8`, `SP_L 12`, `SP_XL 16`, `SP_XXL 24`.

| токен | px | что |
|---|---|---|
| `ROW` | 22 | строка дерева, списка, консоли, таблицы |
| `FIELD_H` | 20 | высота поля / кнопки внутри инспектора и диалогов |
| `CONTROL_H` | 22 | кнопка / поиск / переключатель на полосе инструментов панели |
| `TAB_BAR` | 24 | полоса вкладок дока |
| `STRIP` | 28 | полоса инструментов под вкладкой (`toolbar_strip`, `panel_header`) |
| `MENU_BAR` | 22 | главное меню |
| `MAIN_TOOLBAR` | 32 | главная панель инструментов (кнопки 24 px) |
| `STATUS_BAR` | 22 | строка состояния |
| `MENU_ROW` | 22 | пункт меню, `MENU_WIDTH` 220 |
| `ICON` | 16 | иконка; `ICON_S` 12 — в полях и строках состояния |
| `LABEL_W` | 0.4 ширины, 110…180 | колонка подписей инспектора |
| `INDENT` | 14 | шаг вложенности дерева |

Скругления: `R_S 2` (поля, кнопки, переключатели), `R_M 3` (плашки поверх вида, миниатюры),
`R_L 4` (меню, всплывающие и плавающие окна). Панели — 0. Тени только у меню, подсказок и
плавающих окон.

UI scale (Preferences, 80–200 %) масштабирует всё через `zoom_factor` egui: размеры выше
задаются в точках, поэтому писать «×scale» вручную нельзя.

## Состояния контролов

| состояние | кнопка | строка списка | поле ввода |
|---|---|---|---|
| обычное | `BG_FIELD`, рамка `LINE_STRONG` | прозрачная, без «зебры» | `BG_INSET`, рамка `LINE_STRONG` |
| наведение | `BG_HOVER` | `hover_fill()` | рамка светлее (`LINE_HOVER`) |
| нажатие | `BG_ACTIVE` | — | — |
| фокус | рамка `accent()` | — | рамка `accent()` 1 px |
| выбрано | `accent_soft()` (переключатель) | `selection_fill()`; панель не в фокусе — `selection_unfocused()` | — |
| недоступно | текст `TEXT_DISABLED`, без рамки наведения | текст `TEXT_DISABLED` | текст `TEXT_DISABLED` |

## Виджеты (`theme::…`)

Кнопки — всегда через эти функции:

* `button(ui, label)` — обычная (высота `FIELD_H`); `secondary_button` — то же для диалогов
  (мин. ширина 80);
* `primary_button(ui, label)` — главное действие диалога (заливка акцентом); одна на окно;
* `danger_button(ui, label)` — необратимое действие;
* `ghost_button(ui, label)` — текстовая кнопка без фона (ссылки-действия в строке);
* `icon_text_button(ui, icon, label)` — кнопка полосы инструментов с иконкой;
* `icons::button(ui, icon, selected, tint, tooltip)` — квадратная кнопка-иконка 24 px
  (переключатель, если `selected`); `icons::small_button` — 20 px без фона;
* `toggle_button(ui, &mut on, icon, label, tooltip)` — переключатель с подписью на полосе;
* `pill_toggle(ui, &mut on, icon, color, text, tooltip)` — фильтр-переключатель со
  счётчиком (уровни консоли); прямоугольный, не «таблетка»;
* `segmented(ui, &mut value, options)` — сегменты встык (2D / 3D, List / Tiles, Platform).

Поля и прочее:

* `search_field(ui, &mut text, hint, width)` — поиск с лупой и крестиком (высота `CONTROL_H`);
* `section_label(ui, "MATERIALS")` — подпись группы прописными;
* `section_header(ui, title)` — заголовок раздела в окне настроек: текст + линия;
* `field_label(ui, label, tooltip)` — подпись поля в колонке `LABEL_W`, длинная обрезается
  с многоточием, полный текст — в подсказке;
* `badge(ui, text, color)` — крошечный счётчик (единственная «таблетка»);
* `progress_bar(ui, fraction, text)` — тонкая полоса прогресса (4 px) с подписью;
* `empty_state(ui, icon, title, hint)` — тихое пустое состояние: иконка 24 px, текст
  `TEXT_MUTED`, без крупного заголовка;
* `chip(painter, pos, text, color)` — подпись на полупрозрачной плашке поверх вида;
* `key_value(ui, key, value)` — строка «подпись: значение» в `Grid`;
* `list_row(ui, rect, selected, focused, hovered)` — фон строки списка по состояниям.

Меню: `menu_body(ui)` в начале, `item(label).icon(..).shortcut(..).checked(..)
.enabled_if(..).show(ui)`, `submenu(ui, icon, title, |ui| …)`, `menu_separator(ui)`,
`menu_section(ui, title)`. Пункты 22 px, иконка в колонке 26 px, сочетание клавиш справа
приглушённым цветом, наведение — приглушённый акцент (`mix(BG_RAISED, accent, 0.55)`), как в Unity.
`dropdown_button(ui, "Gizmos", tooltip, |ui| …)` — компактное меню полосы инструментов
(«Gizmos ▾», «Camera ▾», «Layout ▾»).

Окна и диалоги: `dialog_frame(style)` (рамка модального окна: `BG_RAISED`, 1 px `LINE_STRONG`,
радиус 4, отступ 16, тень), `window_frame(style)` для плавающих окон настроек,
`dialog_title(ui, icon, color, title)` — иконка 16 px + заголовок 14 px слева.

Полосы: `panel_header(ui, icon, title, |ui| right)` — полоса 28 px с кнопками справа;
`toolbar_strip(ui, |ui| …)` — полоса 28 px с линией снизу, слева направо.

## Анатомия панели

```
┌ вкладка ─────────────────────────────── ⋮ ┐  TAB_BAR 24, BG_HEADER, выбранная вкладка — BG_PANEL
│ [поиск……]  [фильтр] [фильтр]       [⟳][≡] │  STRIP 28, BG_PANEL, линия LINE снизу
│ строка 22                                  │  ROW 22, отступ слева 8
│ строка 22 (выбрана: selection_fill)        │
└────────────────────────────────────────────┘
 1 px LINE между соседними панелями — без щелей и скруглений
```

* Отступ содержимого от края панели — `SP_M` (8) по горизонтали, 4 по вертикали.
* Заголовок окна показывает вкладка дока — внутри панели название не повторяется.
* Пустое состояние — по центру, тихо, одна строка подсказки.
* Полосы прокрутки тонкие (6 px), появляются при наведении.

## Иконки

Один набор 16 × 16 на пиксельной сетке, линии 1.25–1.5 px, монохромные (цвет текста или
`TEXT_MUTED`). Цвет — только для узнавания типа в Project / Hierarchy (папка — приглушённый
жёлтый `FOLDER`, префаб — `PREFAB`, ошибки / предупреждения консоли — смысловые цвета).
Залитые «мультяшные» фигуры не используются; заливка допустима только у маленьких
элементов (треугольник Play, точки «⋮») и у значков уровня сообщений (Info / Warn / Error).

`icons::paint(painter, rect, Icon::…, color)` рисует в любом квадрате; `icons::inline` (16 px)
и `icons::inline_small` (12 px) — в строке текста. Набор: transport (Play, Pause, Step,
Stop), инструменты (Move, Rotate, Scale, Globe, Local, Magnet, Grid, Gizmo), объекты и
ассеты (Object, Cube, Sphere, Cylinder, Plane, Sprite, Image, Camera, Sun, Bulb, Audio, Ui,
Particles, Tilemap, Animation, Tween, Physics, Collider, Transform, Environment, Prefab,
Scene, Script, Text, File, Folder, FolderOpen), окна (Hierarchy, Inspector, Console, Chart,
Code, Tiles, List), действия (Plus, Close, Check, Search, Gear, Eye, EyeOff, Refresh, Reset,
Undo, Redo, Save, Copy, Trash, Build, Collapse, External, ArrowDown, ArrowUp, More,
Chevron*), состояния (Info, Warn, Error) и добавленные в волне 9: `Target` (кнопка выбора у
поля ссылки), `Lock`, `Unlock`, `Filter`, `Star` (избранное), `Clock` (недавние).

## Можно / нельзя

* Можно: плотные строки, моноширинные числа, подсказки с сочетанием клавиш, линии 1 px.
* Нельзя: числа размеров и цвета прямо в панели; `ui.heading()`; `RichText::strong()` для
  обычного текста; «таблетки»; рамки-карточки вокруг групп полей; цветные заливки фона
  под иконками; эмодзи и символы-картинки вместо иконок; «coming soon».
