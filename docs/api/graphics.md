# Графика: тени, небо, время суток, затенение, контур, сглаживание, лампы, вода

Новые эффекты рендера — **необязательные компоненты** на любом объекте сцены, как `Fog`,
`SkyColors` и `ColorGrading`. Без компонента кадр такой же, как раньше (до пикселя);
`Environment` не менялся. Пресет качества (Project Settings → Graphics,
`ctx.set_quality(...)`) ограничивает то, что компоненты просят.

```rust
use engine::prelude::*;

app.spawn("Look")
    .with(SoftShadows::default())          // каскадные мягкие тени солнца
    .with(Sky { clouds: 0.4, ..Default::default() }) // солнце с ореолом, облака, луна, звёзды
    .with(AmbientOcclusion::default())     // экранное затенение щелей и углов
    .with(Outline::default())              // контур силуэтов и рёбер (низкополигональный стиль)
    .with(PostQuality::default())          // FXAA и блум «13 выборок»
    .with(ManyLights::default())           // все лампы сцены, а не четыре ближайшие
    .with(FillLight::default());           // ambient: небо сверху, отсвет земли снизу
app.spawn("Sun")
    .with(Light::directional(2.4))
    .with(TimeOfDay::sunset());            // поворачивает и окрашивает этот свет по часам
app.spawn("Lamp").at3(0.0, 4.0, 0.0).rotation(Quat::from_rotation_x(-1.57))
    .with(Light::point(Color::rgb(1.0, 0.8, 0.5), 20.0, 12.0))
    .with(SpotLight::default())            // конус вдоль −Z объекта
    .with(LightShadows::default());        // тени от этой лампы
app.spawn("Pond").at3(0.0, 1.5, 0.0)
    .with(Water { size: 16.0, ..Default::default() })
    .with(WaterEffects::default());        // преломление, глубина, пена, отражения
```

## Пресеты качества

Пресет заполняет поля `GraphicsSettings`; в Project Settings → Graphics каждое можно
поменять отдельно (строки Shadow cascades, Soft shadow filter, Ambient occlusion, High
quality bloom, FXAA, Render scale, Terrain detail, Max lights, Shadowed lights, Water detail).

| что (поле) | Low | Medium | High (по умолчанию) |
|---|---|---|---|
| тени солнца (`shadows`) | нет | да | да |
| каскадов `SoftShadows`, не больше (`shadow_cascades`) | 1 | 2 | 4 |
| фильтр края `SoftShadows`, не лучше (`shadow_filter`) | PCF 3×3 | PCF 3×3 | контактное упрочнение |
| дальность теней, потолок (`shadow_distance`) | 20 м | 30 м | 1000 м |
| блум (`bloom`, `bloom_intensity`) | нет | 0.6 × | 1 × |
| блум «13 выборок» `PostQuality` (`high_quality_bloom`) | нет | да | да |
| затенение `AmbientOcclusion` (`ambient_occlusion`) | нет | 8 выборок | 12 выборок |
| FXAA `PostQuality` (`fxaa`) | да | да | да |
| рельеф (`terrain_detail`) | дешёвый: без второй выборки против повторов, скала — плоской проекцией | полный | полный |
| ламп с `ManyLights`, не больше (`max_lights`) | 16 | 64 | 255 |
| ламп с тенью `LightShadows` (`light_shadows`) | 0 | 1 | 2 |
| вода `WaterEffects` (`water_detail`) | 0: волны, рябь, блик | 1: + преломление, цвет по глубине, пена | 2: + отражения сцены |
| масштаб разрешения (`render_scale`) | 1.0 | 1.0 | 1.0 |

Контур `Outline` и облака `Sky` пресетом не ограничиваются (дёшевы).

На Low рельеф заметно дешевле (GTX 1050 Ti, `terrain.scene`: без второй выборки −3 мс, без
трипланара скалы −2 мс GPU из ~7), но на больших площадях виден повтор плиток.

`GraphicsSettings::render_scale` (по умолчанию 1.0 во всех пресетах) — масштаб разрешения
3D-сцены: 0.75 — сцена рисуется в 75 % ширины и высоты и растягивается при сведении кадра,
интерфейс остаётся чётким. На GTX 1050 Ti рельеф упирается в число пикселей: 0.75 сокращает
время GPU на `terrain.scene` с 10.5 до 7.5 мс. Больше 1 — сверхвыборка.

```rust
let mut g = GraphicsSettings::preset(QualityLevel::Medium);
g.render_scale = 0.75;
app.world.resources.insert(g);
```

## `SoftShadows` — каскадные мягкие тени

Без компонента солнце рисует тени одной картой 2048² на область вокруг камеры (PCF 3×3).
С компонентом область до `Environment::shadow_distance` делится по глубине вида на каскады:
у ближнего — маленький участок и чёткая тень, у дальних — большие. Каждый каскад — шар вокруг
своего куска пирамиды камеры, привязанный к текселям: при повороте и движении камеры края
теней не дрожат. Между каскадами тень смешивается, после последнего — плавно гаснет.
Работает для перспективных камер; у ортографической — одна карта, как без компонента.

| поле | по умолчанию | смысл |
|---|---|---|
| `enabled` | `true` | `false` — как без компонента |
| `cascades` | 3 | 1–4 (пресет может уменьшить) |
| `filter` | `ContactHardening` | `Hard` — PCF 3×3, `Soft` — 16 выборок по диску Пуассона, `ContactHardening` — полутень шире вдали от заслонителя |
| `softness` | 2.0 | ширина края в текселях карты |
| `blend` | 0.15 | доля каскада, где тень смешивается со следующим |
| `split` | 0.75 | 0 — равные доли, 1 — логарифмически (ближние мельче) |

Цена: по проходу теней на каскад (draw call'ы теней × каскады). WebGL2: работает (массив
глубины и сравнивающий сэмплер есть в GLSL ES 3.0; фильтр не читает глубину напрямую).

## `Sky` — солнце, рассеяние, облака, луна, звёзды

Без компонента — прежний градиент по высоте солнца. С ним:

* диск солнца размера `sun_size` (градусы) с ореолом `sun_glow` — ярче единицы, блум даёт сияние;
* рассеяние (`scattering`): светлая дымка у горизонта днём, оранжево-розовая полоса заката на
  стороне низкого солнца — только на фоне неба: туман и ambient его не получают, передний план сохраняет контраст; сила следует за яркостью солнца (ночная сцена с «лунным» светом остаётся тёмной);
* облака: `clouds` — покрытие 0…1, `cloud_speed` (м/с), `cloud_scale`, `cloud_color`; край к
  солнцу светится, ночью облака тёмные;
* ночью — луна напротив солнца (`moon`) и мерцающие звёзды (`stars` — яркость).

## `TimeOfDay` — время суток

Кладётся на объект с направленным `Light`. Каждый кадр поворачивает его по часам (`hour`,
0…24; `speed` — игровых часов в секунду, 0 — стоит), меняет цвет (тёплый у горизонта, белый
днём) и яркость (`intensity` днём, `night_intensity` — «луна» ночью, свет тогда идёт с
противоположной стороны). `heading` — направление восхода, `max_elevation` — высота солнца в
полдень. Пресеты: `TimeOfDay::sunrise()`, `noon()`, `sunset()`, `night()`.

## `AmbientOcclusion` — экранное затенение

Щели, углы и земля у основания объектов темнее. Считается по буферу глубины в половинном
разрешении (полусфера выборок вокруг нормали, восстановленной по соседним пикселям) и
размывается с учётом глубины — без ореолов у краёв. Гасит свет сцены до тонмаппинга.

| поле | по умолчанию | смысл |
|---|---|---|
| `radius` | 0.6 | радиус поиска заслонителей, м |
| `intensity` | 0.6 | сила, 0…1 |
| `bias` | 0.03 | смещение против самозатенения, м |

## `Outline` — контур

Линии там, где расстояние до камеры рвётся (силуэты) или нормаль ломается (рёбра граней):
`color`, `strength` (0…1), `thickness` (1…3 пикселя), `depth_threshold` (доля расстояния),
`normal_threshold` (1 − cos угла; 0.3 ≈ 45°).

`AmbientOcclusion` и `Outline` читают многовыборочный буфер глубины — в браузере на WebGL2
это невозможно, там они молча выключены (кадр как без них). Действуют на вид из камеры
сцены (игра, окно Game), не на превью редактора.

## `PostQuality` — FXAA и блум «13 выборок»

`fxaa` — сглаживание по яркости после сведения кадра: края внутри текстур, вырезы, тонкие
линии контура (MSAA их не берёт). `high_quality_bloom` — уменьшение кадра для блума
фильтром из 13 выборок со средним Кариса на первом шаге: ровнее, яркие точки не мерцают
(Medium и выше). Оба работают и на WebGL2.

## Варианты шейдера: что стоит выключенный эффект

Шейдер мешей и рельефа собирается в вариантах: одна карта теней или каскады (`SoftShadows`),
без ламп или с лампами (`SpotLight`, `LightShadows`, `ManyLights`, `FillLight`). Кадр берёт
вариант, которому хватает того, что есть в сцене; нужные варианты компилируются при первом
кадре, где они понадобились. Сцена без этих компонентов рисуется прежним шейдером — без
кода каскадов и ламп и без их выборок (GTX 1050 Ti, Tashbazar: время GPU как до появления
`SoftShadows`).

## Лампы: прожекторы, много ламп, тени ламп, заполняющий свет

Без компонентов меши и рельеф освещают солнце и **четыре** ближайшие к камере точечные лампы.
Компоненты ниже включают вариант шейдера «с лампами»:

* `SpotLight` — на объекте с точечным `Light`: конус вдоль оси «вперёд» (−Z) объекта.
  `angle` — полный угол конуса (градусы), `inner_angle` — яркая середина; дальность —
  `Light::range`.
* `ManyLights` — все лампы сцены (до `max_lights`, пресет ограничивает: Low 16, Medium 64,
  High 255; ближние к камере — первыми). Без него — четыре ближайшие, как раньше.
* `LightShadows` — на объекте лампы: она отбрасывает тени (`bias` — сдвиг против
  самозатенения, м). Точечная лампа — шесть граней куба (шесть проходов теней), прожектор —
  одна. Сколько ламп с тенью — пресет (`light_shadows`: Low 0, Medium 1, High 2), ближние к
  камере первыми. Флаг `Light::shadows` по-прежнему относится только к солнцу.
* `FillLight` — ambient полусферой: сверху — цвет неба сцены (`sky_tint` 1) или
  `sky_color`, снизу — отражённый от земли свет `ground_color` × `bounce` (ярче, когда
  солнце высоко). Сила общего ambient — `Environment::ambient` × `intensity`.

Как устроено: лампы раскладываются на CPU по кластерам (16 × 9 по экрану × 16 слоёв по
глубине, до 16 ламп на ячейку), пиксель считает только лампы своей ячейки. Данные ламп,
ячеек и граней теней лежат в текстурах — работает в WebGL2 (нет storage-буферов и
вычислительных шейдеров) и не занимает компонентов интерполяции (у шейдера мешей заняты 30
из 31 — передать список ламп от вершины к пикселю нельзя, поэтому выбор «N ближайших ламп
на объект» отвергнут; он к тому же ломается на больших поверхностях вроде земли). Тени
ламп — атлас 2048² из плиток 512².

Цена (GTX 1050 Ti, 1280×720, сцена `lights_200`: 200 ламп, 400 столбов): без компонентов
1.74 мс; `ManyLights` — 2.94 мс (GPU +0.9 мс, раскладка на CPU +0.2 мс); с `FillLight` —
2.96 мс; с тенями двух ламп (High, 12 граней) — 3.12 мс.

## `WaterEffects` — вода с эффектами

На объекте с `Water`. Без компонента вода как раньше.

| поле | по умолчанию | смысл |
|---|---|---|
| `shallow_color` | бирюзовый | цвет мелкой воды |
| `clarity` | 1.5 | на сколько метров толщины видно дно |
| `refraction` | 0.35 | искажение дна волнами |
| `foam`, `foam_width` | 0.8, 0.18 м | пена у берега и предметов: сила и ширина (по высоте воды над дном) |
| `ripples`, `ripple_scale` | 0.6, 3 м | мелкая рябь (две бегущие процедурные карты нормалей) |
| `glint` | 1.0 | блик солнца размером с диск `Sky` |
| `reflections` | 1.0 | доля отражений сцены (пресет High) |
| `stylized` | `false` | плоский стиль: непрозрачная вода полосами цвета, гранёные волны, чёткая пена |

Пресет (`water_detail`): Low — рябь и блик; Medium — плюс преломление, цвет по толщине воды и
пена; High — плюс отражения сцены по экрану (луч по буферу глубины; что вне кадра — небо).
Плоских (planar) отражений нет. Для преломления и пены кадр до воды сводится в отдельную
текстуру и глубина читается под водой — в браузере на WebGL2 этого нельзя, там остаются
рябь, блик и плоский стиль.

## Проверки

`crates/engine/tests/graphics.rs` — числом: тень за кубом темнее освещённой земли на 6 / 25 /
60 м, пресеты Low / Medium ограничивают каскады, выключенный компонент рисует кадр до пикселя
как без него, диск солнца ярче неба, облака закрывают синеву, ночью видны луна и звёзды;
затенение темнит складку у куба и не трогает открытую землю (на Low его нет), контур даёт
тёмные линии, FXAA меняет только края, `render_scale` 0.5 сохраняет размер и яркость кадра;
прожектор светит только в конусе, `ManyLights` освещает землю под всеми десятью лампами (без
него — под четырьмя), три лампы через кластеры дают тот же кадр, что прежний путь (разница
≤ 2 на канал), `LightShadows` даёт тень за кубом (на Low — нет), `FillLight` окрашивает тень;
вода с эффектами светлее над отмелью, даёт пену у столба и (на High) отражение стены; каждый
выключенный компонент рисует кадр до пикселя как без него.
