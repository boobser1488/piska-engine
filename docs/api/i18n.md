# Перевод интерфейса (i18n)

Редактор, Piska Hub и Piska Modeler можно переключить на русский язык без перезапуска:
**Preferences → General → Interface → Language** (в хабе — Settings → Language, в
редакторе моделей — тот же выбор из общей настройки). Значения: `Auto` (язык системы:
русский, если система русская, иначе английский), `English`, `Русский`. Выбор лежит в
`editor.ron` (`language: auto|en|ru`) и общий для всех трёх программ.

Переводится **интерфейс** — подписи, подсказки, меню, диалоги, сообщения интерфейса.
Остаётся английским: строки журнала и Console, сообщения компиляторов и Cargo, тексты
ошибок библиотек, имена типов и компонентов, имена полей в Inspector (они берутся из
кода игры), имена файлов и расширения, имена создаваемых объектов (`Main Camera`,
`Directional Light` попадают в сцену и не зависят от языка интерфейса).

## Слой перевода — крейт `engine-i18n`

Без зависимостей, один файл `crates/engine-i18n/src/lib.rs` и каталог
`crates/engine-i18n/locale/ru.po`. Ключ перевода — **английский текст**: в коде читается
английский, а строка без перевода показывается как есть.

```rust
use engine_editor::kit::i18n::{tr, tr_s, trf, trn, tr_ctx, n_, Language};

ui.label(tr_s("Add Component"));                       // &'static str — подходит везде, где был литерал
ui.button(tr("Save"));                                 // Cow<str>
let text = trf!("Saved {path}", path = path.display()); // String, подстановки по имени
let text = trf!("Cannot open `{}`: {}", dir, err);       // или по порядку, как в format!
let text = trn!("{n} object", "{n} objects", count);    // форма множественного числа; {n} — число
ui.menu_button(tr_ctx("menu", "Edit"), |ui| { … });     // контекст: «Edit» в меню ≠ «Edit» в режиме
const TITLES: [&str; 2] = [n_("Move"), n_("Rotate")];   // таблица в const: ключ помечен, перевод — при показе
ui.label(tr_s(TITLES[i]));
```

* `tr` / `tr_s` — строка; `tr_s` принимает и отдаёт `&'static str`, поэтому годится для
  аргументов `&str`, веток `if` / `match` и полей структур. `tr_ctx`, `tr_ctx_s` — с контекстом.
* `trf!` — подстановки `{имя}`, `{}` (по порядку), `{0}`; формат `{x:.1}` в шаблоне не
  нужен: число форматируют в аргументе (`x = format!("{:.1}", x)`). `{{` и `}}` — скобки.
* `trn!` / `tr_n` — множественное число. У русского три формы (1, 21, 101… / 2–4, 22–24… /
  0, 5–20, 25–30…); первый аргумент — единственное число английского и ключ каталога,
  второй — множественное.
* `set(Language)` / `current()` — язык процесса; интерфейс egui рисуется каждый кадр, поэтому
  новый язык виден сразу. `Language::system()` — язык системы (на Windows — язык интерфейса
  пользователя, иначе `LC_ALL`, `LC_MESSAGES`, `LANGUAGE`, `LANG`).
* Настройка: `Preferences.language: Option<Language>` (`None` — Auto),
  `Preferences::apply_language()`; `Preferences::load()` применяет язык при запуске.

Что не переводить `tr`-ом: идентификаторы (`Id::new`, ключи настроек и сохранённых
раскладок), сравниваемые строки (`importer == "Material"`), имена файлов, форматы
файлов, протоколы. Если строка похожа на текст, но им не является, — `// i18n-skip` в
той же (или предыдущей) строке либо строка в `tools/ui_strings_ignore.txt`.

## Каталог `ru.po`

Подмножество gettext, правится руками или в Poedit:

```po
#: crates/engine-editor/src/hierarchy.rs:217
msgid "Create a new object in the scene"
msgstr "Создать новый объект в сцене"

msgctxt "menu"
msgid "Edit"
msgstr "Правка"

msgid "{n} object"
msgid_plural "{n} objects"
msgstr[0] "{n} объект"
msgstr[1] "{n} объекта"
msgstr[2] "{n} объектов"
```

Пустой `msgstr` — «не переведено»: показывается английский. Загрузчик собирает все ошибки
(повтор ключа, чужие подстановки в переводе, не то число форм) и не отбрасывает остальное;
тест `embedded_russian_catalogue_is_well_formed` требует, чтобы их не было. Правила
перевода и термины — `docs/design/glossary-ru.md`.

## Инструменты

```text
python tools/extract_ui_strings.py --stats           # сколько строк обёрнуто и сколько ещё нет, по файлам
python tools/extract_ui_strings.py                   # список строк с файлом:строкой
python tools/extract_ui_strings.py --check           # код выхода 1: нет перевода / лишняя запись / не те подстановки
python tools/extract_ui_strings.py --check --scope modeler   # одна из программ: editor, hub, modeler
python tools/extract_ui_strings.py --update          # дописать в ru.po недостающие ключи с пустым msgstr
python tools/wrap_ui_strings.py --scope editor --dry # механически обернуть новые строки в tr_s / trf!
```

`--check` идёт и как тест (`crates/engine/tests/editor_l10n.rs`,
`the_catalogue_matches_the_code`). Находит строки разбор лексем Rust (комментарии, сырые
строки, `#[cfg(test)]` пропускаются): аргументы функций интерфейса, `format!` с фразой,
«человекоподобные» литералы. Строки в таблицах `const` помечают `n_("…")`; ключи, которые
строятся на лету, перечисляют в комментарии `// i18n-keys: "…" "…"`, ключи с контекстом в
таблицах — `// i18n-ctx: имя "ключ" "ключ"`.

## Как добавить язык

1. `crates/engine-i18n/src/lib.rs`: вариант `Language::…` в `ALL`, `code`, `native_name`,
   `from_code`, `from_locale_tag`, `plural_forms`, `plural_index` (правило из CLDR),
   `catalogue()` и вшитый файл `locale/<код>.po`.
2. Перевести каталог: `tools/extract_ui_strings.py --update --catalogue <файл.po>` создаёт заготовки
   с пустым `msgstr`; `--check --catalogue <файл.po>` сверяет их с кодом.
3. Тест `crates/engine/tests/editor_l10n.rs` проходит по окнам и меню на выбранном языке и
   показывает надписи, оставшиеся английскими; `bundled_fonts_cover_…` проверяет, что
   шрифты рисуют все буквы каталога (системные шрифты Windows; для Linux / Android / web —
   встроенные шрифты egui; нужны ли дополнительные — зависит от алфавита).

## Ограничения

* Подписи полей компонентов в Inspector строятся из имён полей кода и остаются английскими:
  реестр не хранит отображаемых имён.
* Шрифты egui «из коробки» не рисуют некоторые знаки (`→`, `⋯`): без системных шрифтов они
  показываются квадратами — это и в английском тексте.
* Piska Modeler живёт в отдельном репозитории и держит копию слоя в `modeler/vendor/engine-i18n`;
  обновить: `python modeler/scripts/sync_from_engine.py`.
