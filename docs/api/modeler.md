# Piska Modeler — редактор низкополигональных моделей

Простой редактор моделей «из коробок» с пиксельной текстурой: модель собирается из
кубоидов и простых форм, складывается в группы с точками вращения, а текстура рисуется
прямо по модели. Результат — файл `.pmodel`, который движок импортирует как меш с
текстурой (`MeshRenderer` берёт его напрямую).

* Библиотека: крейт `engine-modeler` (документ, операции, история, развёртка, рисование,
  формат, экспорт) — без интерфейса, зависит только от glam / serde / image.
* Интерфейс: модуль `engine_modeler::ui` (фича `ui`, egui).
* Отдельная программа: `cargo run -p piska-modeler -- [файл.pmodel …]`.
* Из редактора движка: двойной щелчок по `.pmodel` в окне Project (или пункт «Open in
  Piska Modeler»), Assets ▸ New Model (Piska Modeler) — создаёт пустую `model.pmodel` в
  открытом каталоге и открывает её. Редактор моделей открывается отдельным окном
  (программа `piska-modeler` должна лежать рядом с программой редактора — `cargo build -p
  piska-modeler` в тот же каталог сборки — или путь к ней задаётся переменной
  `PISKA_MODELER`). Сохранённая модель подхватывается, когда окно редактора снова получает
  фокус: ассеты перечитываются, меш и миниатюра обновляются.
* Сцена с образцами: `cargo run --example modeler_scene` (`assets/scenes/models.scene`).
* Образцы: `assets/models/{crate,lantern,pine,rover}.pmodel`, генератор —
  `cargo run -p engine-modeler --example gen_samples`.

Чего здесь нет (сознательно — редактор «простой»): скелетной анимации и ключевых кадров,
скульптинга, правки отдельных вершин и полигонов, наборов PBR-текстур (нормали,
шероховатость). Группы с точками вращения готовы для анимации, но анимировать их пока
нужно кодом игры.

## Окно

```
┌ меню: File  Edit  Model  Texture  View    вкладки документов ───────────────────────┐
│ [Edit|Paint]  кнопки режима (добавить формы / кисть)   …   undo redo  вид  сетка     │
├──┬──────────────────────────────────────────────────────────┬───────────────────────┤
│ин│                                                          │ OUTLINER              │
│ст│                    3D-вид                    значок осей │ ELEMENT               │
│ру│                                                          │ UV                    │
│ме│                                                          │ PALETTE               │
│нт│                                                          │ TEXTURES              │
├──┴──────────────────────────────────────────────────────────┴───────────────────────┤
│ выделение · подсказка инструмента                     EDIT · snap 1 px · 16 px = 1 m │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

Два режима (**Tab**): **Edit** — форма, **Paint** — рисование. Слева — инструменты
режима, справа — сворачиваемые панели, внизу — что выделено и подсказка инструмента.
Цвета — общая тема Piska (тёмная нейтральная палитра редактора).

### 3D-вид

* Правая кнопка — вращение камеры, Shift + правая или средняя — сдвиг, колесо — масштаб,
  Alt + левая — тоже вращение.
* Значок осей в правом верхнем углу: щелчок по концу оси ставит камеру с этой стороны.
* **1 / 3 / 7** — спереди / справа / сверху, **Ctrl+1/3/7** — сзади / слева / снизу,
  **5** — перспектива ↔ ортография, **F** — показать выделенное (или всю модель).
* Сетка на земле: мелкая — 1 px, крупная — метр (16 px), оси X красная и Z синяя,
  светлый квадрат 16×16 у начала координат — один блок. Модель закрывает сетку по глубине.
* Режимы показа: Textured, Solid (форма без картинок), Wireframe. View ▸ Smooth Edges —
  сглаживание (2× сверхвыборка).
* Наведение подсвечивает элемент, выделенное обведено акцентом; у выделенного элемента —
  **линейка**: размеры по X, Y, Z в пикселях вдоль ближних рёбер (View ▸ Size Ruler).
* «Лицо» модели — северная сторона (−Z), как «вперёд» у объектов движка: вид **1**
  смотрит на него.

Вид рисует программный растеризатор (z-буфер, текстуры «ближайшим соседом», плоский свет):
одинаково в отдельной программе, в редакторе и в тестах без видеокарты, пиксели всегда
резкие. Кадр перерисовывается только когда меняются модель, камера, размер или настройки
вида.

### Режим Edit

| инструмент | клавиша | что делает |
|---|---|---|
| Select | Q | щелчок — выбрать, Ctrl / Shift — добавить; протяжка по пустому — рамка |
| Move | W | стрелки — вдоль оси, квадрат в центре — в плоскости экрана |
| Rotate | E | кольца вокруг точки вращения |
| Resize | R | ручка стороны: коробка растёт с этой стороны, противоположная стоит на месте |
| Pivot | P | двигает точку вращения, не трогая форму |

Привязка: панель **Snap** (0.25 … 16 px или Off) и шаг поворота (22.5° / 15° / 5° /
Free). **Ctrl** во время перетаскивания временно включает / выключает привязку,
**Shift** — четверть шага (поворот — по 1°). Щелчок по элементу в виде выбирает и его
сторону (для UV и цвета).

Кнопки панели: добавить **Cuboid, Plane, Cylinder, Cone, Sphere, Group** (в выделенную
группу или рядом с выделенным), **Mirror X**, **Flip X**, **Center**, **Duplicate**,
**Delete**. Меню Model: Group Selection (Ctrl+G), Flip X/Y/Z, Align (Min / Center / Max по
каждой оси), Distribute, Center on Origin, Hide / Show (H), Unlink Twin.

**Отражённые близнецы (Mirror X, M).** Создаёт копию элемента по ту сторону X = 0 и
связывает их: любая правка одного (сдвиг, размер, поворот, точка вращения) повторяется на
другом зеркально. Близнец показывает ту же картинку текстуры, отражённую, — рисовать
достаточно одну сторону. Имена меняются парами: `arm_left` ↔ `arm_right`, `leg.L` ↔
`leg.R`. Связь видна значком в Outliner, разрывается Unlink Twin.

### Режим Paint

| инструмент | клавиша | что делает |
|---|---|---|
| Pencil | B | рисует текселями (размер кисти — `[` и `]`) |
| Eraser | E | делает тексели прозрачными |
| Fill | G | заливка стороны или связной области цвета (Fill: Face / Connected) |
| Line | L | прямая на одной стороне (виден предпросмотр, пока тянете) |
| Rectangle | U | прямоугольник на стороне; с Shift — залитый |
| Color Picker | I | взять цвет (Alt + щелчок не нужен: это отдельный инструмент) |
| Shade | D | осветлить; с Shift — затемнить (каждый тексель — один раз за штрих) |

Рисовать можно прямо по модели (луч → сторона → тексель; кисть не вылезает за сторону) и
в UV-панели. Под курсором обводятся тексели, которые закрасит кисть. **Mirror Painting** —
рисует одновременно и по зеркальной точке по ту сторону X = 0. **X** меняет основной и
второй цвет. Каждый штрих — один шаг Undo.

### Панели

* **Outliner** — дерево групп и элементов. Щелчок — выбрать (Ctrl — добавить), двойной —
  переименовать, перетаскивание: на верх / низ строки — поставить перед / после, в середину
  группы — внутрь, под список — в корень. Глаз — видимость в окне (на экспорт не влияет),
  замок — элемент нельзя выбрать в виде, двигать и рисовать по нему. Правая кнопка —
  меню (Rename, Duplicate, Group, Mirror X, Unlink Twin, Delete).
* **Element** — числа выделенного: имя; форма (и число сторон / колец); Position (угол
  коробки), Size, Pivot, Rotation (градусы, порядок X → Y → Z), Inflate (коробка больше,
  текстура та же); стороны N E S W U D (выбрать сторону), Visible, Emissive, Tint (оттенок
  стороны), Texture, Box layout. Без выбранной стороны свойства применяются ко всем.
  Группа: Origin (сустав) и Rotation.
* **UV** — текстура с прямоугольниками сторон выделенного. Edit: щелчок — выбрать
  сторону, перетаскивание — сдвинуть (по целым текселям), уголок — растянуть; кнопки
  «повернуть на 90°», «отразить по горизонтали / вертикали», поля X Y W H. Сдвинутая руками
  сторона выключает Box layout у элемента. Колесо — масштаб, правая / средняя кнопка —
  сдвиг; при крупном масштабе видна сетка пикселей. Paint: рисование по атласу.
  Кнопки Auto UV и Repack.
* **Palette** — основной и второй цвет, HEX-поле, HSV-круг, недавние цвета, сохранённая
  палитра (+ добавляет, правая кнопка убирает).
* **Textures** — текстуры модели; Add, Resize…, Import PNG…, Export PNG….

### Развёртка

Новый элемент получает **развёртку коробкой** (Box layout): стороны раскладываются как
бумажная коробка — сверху Up и Down, ниже полоса East, North, West, South; соседние
стороны стыкуются краями, как на модели. Место ищется свободное; если атласа не хватает, он
растёт вдвое (до 2048). Новые стороны заливаются светло-серым, чтобы было по чему
рисовать. Плотность — 1 тексель на пиксель модели (`texel_density`). При изменении размера
развёртка остаётся на месте, если помещается, иначе переезжает вместе с картинкой.
**Repack** плотно перекладывает все развёртки (большие первыми); нарисованное переезжает
вместе с ними.

### Файлы, автосохранение, буфер

* File: New, Open…, Save (Ctrl+S), Save As…, Import Texture (PNG), Import Reference
  (.obj, .glb), Export glTF Binary (.glb), Export Wavefront (.obj + .mtl), Export Texture
  (PNG), Close Document. Окно пути принимает относительные пути (от каталога документа) и
  показывает подходящие файлы рядом.
* Несколько документов — вкладками; **Ctrl+C / Ctrl+V** копирует элементы и группы вместе
  с картинками их развёрток и между документами.
* Каждые 20 с несохранённый документ пишется в файл восстановления во временном каталоге
  ОС (`piska-modeler/recovery`). При следующем открытии появится полоса «Unsaved changes
  from an earlier session were found» с Restore / Discard.
* Текстура, импортированная из PNG, перечитывается, когда файл меняется на диске.

## Формат `.pmodel`

Один текстовый RON-файл, текстуры внутри (PNG в base64). Файл самодостаточен: его можно
перенести, положить в пак ассетов (веб, Android) и перезагрузить одним событием «файл
изменился». Переводы строк — всегда `\n`; одинаковый документ даёт одинаковые байты.

В конце файла — раздел `baked`: та же модель, уже «запечённая» для движка (вершины в
метрах, нормали, UV, индексы и общий атлас PNG). Он переписывается при каждом сохранении;
движок (`engine-assets`) читает только его, поэтому коду игры не нужен редактор моделей.
Файл без этого раздела (созданный руками или через New Model и ещё не сохранённый в
Piska Modeler) движок не загрузит и скажет, что делать.

```ron
(
    format: "piska-model",
    version: 1,
    model: (
        name: "crate",
        units_per_metre: 16.0,     // пикселей модели в метре
        texel_density: 1.0,        // текселей на пиксель при развёртке коробкой
        textures: [(name: "atlas", image: "iVBORw0KGgoAAAANSUhEUg…")],
        nodes: [
            (id: 1, name: "body", kind: Element((
                shape: Cuboid,               // Plane, Cylinder(segments: 8), Cone(…), Sphere(segments: 8, rings: 6)
                from: (-8.0, 0.0, -8.0),     // минимальный угол коробки
                size: (16.0, 16.0, 16.0),
                pivot: (0.0, 8.0, 0.0),
                rotation: (0.0, 0.0, 0.0),   // градусы, X → Y → Z
                inflate: 0.0,
                faces: [ /* North, East, South, West, Up, Down */
                    (enabled: true, texture: 0, uv: (x: 16.0, y: 16.0, w: 16.0, h: 16.0,
                     rotation: 0, flip_u: false, flip_v: false), tint: (255, 255, 255, 255), emissive: false),
                    …
                ],
                box_uv: true,
                uv_origin: (0, 0),
            ))),
            (id: 2, name: "lid", parent: Some(3), kind: Group((origin: (0.0, 16.0, -8.0), rotation: (0.0, 0.0, 0.0)))),
        ],
        next_id: 4,
    ),
    baked: (positions: [-0.5, 0.0, …], normals: […], uvs: […], indices: [0, 2, 1, …], texture: Some("iVBOR…")),
)
```

* Координаты элементов — абсолютные (в пространстве модели до поворотов групп); группа
  поворачивает содержимое вокруг `origin`: `мир = G_родитель · G_группа · E_элемент · v`.
* Y вверх, «север» — −Z, 16 единиц = 1 м.
* Чужой файл или файл новой версии даёт понятную ошибку; битые ссылки (родитель, близнец,
  номер текстуры) при чтении чинятся.
* `references` — опорные меши (импорт .obj / .glb): только для показа, на экспорт не идут.

## Движок: `.pmodel` как меш

`.pmodel` в каталоге ассетов — ассет типа `Mesh` (импортёр в `.meta` — `Mesh`, фильтр
текстуры — `Nearest`). Он годится везде, где годится `.obj` / `.glb`:

```rust
use engine::prelude::*;

let assets = app.world.resources.get::<AssetDatabase>().unwrap();
let crate_mesh = assets.handle::<Mesh>("models/crate.pmodel")?;
app.spawn("Crate").with(MeshRenderer::asset(crate_mesh));   // текстура модели — сама
```

Как это устроено («запекание», `engine_modeler::bake`):

* все элементы сводятся в один меш в метрах (повороты групп применены), нормали плоские;
* все текстуры складываются в один атлас (друг под другом), стороны с оттенком (`tint`)
  получают свою подкрашенную копию картинки внизу атласа;
* если у `MeshRenderer` не назначена `texture`, рендерер берёт атлас самой модели;
  назначенная `texture` его заменяет; `color` умножается на текстуру (по умолчанию он
  серый `#c8c8c8` — для точных цветов поставьте белый, как в `scenes/models.scene`);
* в редакторе у модели есть отрисованная миниатюра в окне Project (как у `.obj` / `.glb`);
  сохранённая в Piska Modeler модель обновляется, когда окно редактора получает фокус;
* из пака (веб, Android) модель грузится так же: `AssetDatabase::load_mesh` даёт меш,
  `AssetDatabase::read_image` — атлас, `has_embedded_texture(guid)` — есть ли он.

Ограничения движка: рендерер знает один материал на объект, поэтому флаг Emissive сторон
в движке не светится сам по себе (задайте `MeshRenderer::emissive`, если нужно; в `.glb`
светящиеся стороны экспортируются отдельным материалом с emissive-текстурой). Иерархия
групп в движке не сохраняется — чтобы двигать части отдельно, экспортируйте `.glb`
или сделайте несколько моделей.

## Экспорт

* **`.glb`** (glTF 2.0 одним файлом): узел на группу (перенос и поворот вокруг её точки —
  иерархия пригодна для анимации в других программах), меш группы — её элементы, примитив
  на пару «текстура, свечение»; метры; PNG внутри файла, фильтр «ближайший», альфа MASK;
  оттенки — цвета вершин `COLOR_0`. Загрузчик движка читает этот файл (проверено тестом).
* **`.obj` + `.mtl` + PNG**: объект на элемент, материал на текстуру (`map_Kd`, у
  светящихся — `map_Ke`), V перевёрнута по правилам OBJ.
* Импорт `.obj` / `.glb` — только как опорный меш для обрисовки (серый, не
  редактируется); кубоиды из чужих файлов не восстанавливаются.

## Библиотека

```rust
use engine_modeler::{ops, format, export, Document, Element, FaceDir, Session, Shape};
use glam::Vec3;

let mut session = Session::new(Document::new("tower"));
let base = session.edit("Add", |doc| {
    ops::add_element(doc, "base", Element::cuboid(Vec3::new(-8.0, 0.0, -8.0), Vec3::new(16.0, 4.0, 16.0)), None)
});
let roof = session.edit("Add", |doc| {
    ops::add_element(doc, "roof", Element::new(Shape::Cone { segments: 8 }, Vec3::new(-8.0, 4.0, -8.0), Vec3::splat(16.0)), None)
});
session.edit("Grow", |doc| ops::resize_face(doc, base, FaceDir::Up, 4.0)); // верх выше, низ на месте
session.edit("Paint", |doc| {
    let rect = doc.element(base).unwrap().face(FaceDir::North).uv;
    engine_modeler::paint::fill_clip(&mut doc.textures[0].image, rect.texel_bounds(), [120, 90, 60, 255]);
});
session.undo();                       // снимает заливку
format::save(&session.doc, "assets/models/tower.pmodel")?;
export::write_glb(&session.doc, "tower.glb")?;
```

| модуль | главное |
|---|---|
| `doc` | `Document`, `Node { id, name, parent, visible, locked, kind }`, `NodeKind::{Group, Element}`, `Element { shape, from, size, pivot, rotation, inflate, faces, box_uv, uv_origin, twin }`, `Face { enabled, texture, uv, tint, emissive }`, `UvRect`, `FaceDir`, `Shape` |
| `ops` | `add_element`, `default_element`, `add_group`, `delete`, `duplicate`, `rename`, `set_visible`, `set_locked`, `reparent(doc, id, parent, index)`, `move_by`, `set_element`, `set_group`, `resize_face`, `rotate_by`, `flip`, `center`, `align`, `distribute`, `mirror_x`, `unlink_twin`, `sync_twins`, `auto_uv`, `set_face_uv`, `add_texture`, `import_texture`, `resize_texture` |
| `session` | `Session { doc, selection, face }`: `edit(label, f)`, `begin` / `commit` / `cancel` (длинная правка — один шаг), `undo` / `redo`, `is_dirty` / `mark_saved`, `copy` / `paste` |
| `uv` | `footprint`, `layout_box`, `place`, `refit`, `repack`, `find_free`, `MAX_TEXTURE_SIZE` |
| `paint` | `dab`, `line`, `rectangle`, `fill_clip`, `flood_fill`, `shade`, `pick`, `brush_texels` |
| `geometry` | `build_mesh(doc, BuildOptions)` → `BuiltMesh { vertices, triangles, polygons }` |
| `camera` | `Camera` (орбита, `ray`, `set_preset`, `frame`), `raycast(mesh, ray, filter)` → `Hit`, `Hit::texel(doc)` |
| `raster` | `render(doc, mesh, camera, options, frame)` — программный растеризатор |
| `format` | `to_string` / `from_str`, `save` / `load`, `recovery_path` |
| `bake` | `bake(doc)` → `BakedModel { positions, normals, uvs, indices, texture }`; `bake_bytes(bytes)` |
| `export` | `to_glb` / `write_glb`, `to_obj` / `write_obj` |
| `import` | `reference_from_bytes` / `reference_from_file` |
| `samples` | `all()`: crate, lantern, pine, rover |

Интерфейс (`features = ["ui"]`): `ModelerApp::new()`, `open(path)`, `open_document(doc,
path)`, `show(&mut egui::Ui)` — нарисовать окно в любом месте, `run(Command)` — любая
команда меню, `mode()`, `tool()`, `session()` / `session_mut()`, `take_saved_paths()` (для
перезагрузки ассетов), `has_unsaved_changes()`, для тестов — `button_id("add.cuboid")`,
`outliner_row_id(id)`, `viewport_rect()`, `world_to_screen(p)`, `resize_handle(face)`,
`render_count()`.

Снимки без окна: `cargo run -p piska-modeler -- --sample rover --screenshot out.png
--size 1440x860` (ещё `--paint`, `--tool`, `--view front`, `--ortho`, `--select <узел>`,
`--face north`, `--pointer X,Y`, `--scale 1.25`, `--frames N`).
