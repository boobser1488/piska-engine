# Хранитель фонаря

2D-платформер на Piska Engine. Маленький дух-фонарь спускается по шести тёмным пещерам.
В каждой — парящие светлячки: соберите нужное число, и арка выхода загорится. Пропасти,
шипы, хрупкие и движущиеся платформы, пружины, контрольные точки, четыре вида врагов
и босс в конце.

## Правила в пяти строках

1. У духа три сердца. Враг, снаряд, шипы или пропасть отнимают сердце; после удара —
   полторы секунды неуязвимости. Шипы и пропасть возвращают на последнюю безопасную землю.
2. Нет сердец — «фонарь погас»: можно продолжить с контрольной точки или начать заново.
3. Светлячки светят и тянутся к игроку. Нужное число (счётчик слева вверху) открывает выход;
   запертые ворота тоже требуют светлячков. В каждом уровне спрятан один золотой.
4. Врагов (кроме тяжеляков) можно раздавить прыжком сверху. Тяжеляка не раздавить:
   обойти, перепрыгнуть или пробежать рывком.
5. Звёзды за уровень: ★ дошли до выхода; ★★ собрано не менее 60 % светлячков и не больше
   двух падений; ★★★ ещё и золотой светлячок, и время не хуже контрольного.

Двойной прыжок открывается в конце 2-го уровня, рывок — в конце 4-го. Следующий уровень
открывается, когда пройден предыдущий.

## Управление

| | Клавиатура | Геймпад |
|---|---|---|
| Бег | A / D, ← / → | левый стик, крестовина |
| Прыжок (держите — выше) | Пробел, W, ↑ | A (South) |
| Второй прыжок в воздухе | то же (после 2-го уровня) | то же |
| Рывок (после 4-го уровня) | Shift, X | X (West), RB, RT |
| Вниз сквозь «облачко» | S / ↓ + прыжок | стик вниз + A |
| Пауза | Esc, P | Start |
| Меню | мышь, Tab / стрелки, Enter | крестовина / стик, A, B (назад) |

Касания (телефон, планшет): после первого касания экрана внизу появляются кнопки
«влево», «вправо», «рывок» и «прыжок».

## Запуск

```bash
cargo run -p lantern                                   # играть
ENGINE_FRAMES=600 cargo run -p lantern                 # 600 кадров и выход; FPS — в логе
cargo test -p lantern                                  # тесты без окна
cargo check -p lantern --target wasm32-unknown-unknown # проверка веб-сборки
```

Снимки экрана без окна (меню, уровни, пауза, результаты):

```bash
LANTERN_SCREEN=level3 LANTERN_PLAYER=40,9 ENGINE_SCREENSHOT=shot.png ENGINE_FRAMES=30 \
    cargo run -p lantern --example shots
LANTERN_SCREEN=level2 LANTERN_CAM=34,15,16 ENGINE_SCREENSHOT=overview.png \
    cargo run -p lantern --example shots        # обзор уровня неподвижной камерой
```

## Экспорт

```bash
cargo run -p piska-export -- web --game lantern --release       # dist/lantern/web
cargo run -p piska-export -- serve dist/lantern/web --open
cargo run -p piska-export -- windows --game lantern --release   # dist/lantern/windows
```

Подробности — `docs/api/export.md`. Игра не читает файлы напрямую и не использует
потоки и системное время, поэтому одна и та же `build()` работает на десктопе, в браузере
и на Android. В браузере кнопки «Выход» в меню нет.

## Устройство

* `src/phys.rs` — кинематика по сетке тайлов (чистые функции, тесты внутри).
* `src/player.rs` — игрок; `enemies.rs`, `boss.rs` — враги и босс; `objects.rs` — предметы
  и механизмы; `level.rs` — менеджер уровня (правила, HUD, пауза, результаты);
  `menu.rs` — меню; `sfx.rs` — весь звук из синтезатора; `controls.rs` — привязки и касания.
* `assets/scenes/*.scene` — карты. Их пишет `tools/gen_levels.py`: уровни описаны там
  вручную кусками, построитель проверяет ширину ям и высоту ступеней основного маршрута.
  Эскизы карт — `tools/preview/levelN.txt`.
* `assets/sprites/*.png` — рисует `tools/gen_assets.py` (Python, Pillow, numpy).

```bash
python games/lantern/tools/gen_assets.py   # картинки и их .meta
python games/lantern/tools/gen_levels.py   # сцены уровней и меню
```
