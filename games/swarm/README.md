# Рой

Аркадный шутер на выживание в круглой арене, сделанный на Piska Engine.
Одинокий дрон-ремонтник защищает **реактор** в центре арены от волн взбесившихся машин.
У дрона и у реактора есть своё здоровье. Реактор — это вся игра: если его прочность упала до
нуля, забег проигран. Погибший дрон возвращается через три секунды, но реактор платит за
него 25 прочности.

## Правила в пяти строках

1. Двигайся, целься и стреляй: враги выходят на край арены (место появления помечено
   меткой за секунду до выхода) и идут к тебе или к реактору.
2. Убитые враги роняют обломки; обломки летят к дрону (магнит) и заполняют шкалу опыта.
   Новый уровень — карточка улучшений прямо посреди волны.
3. После каждой волны выбери одно из трёх случайных улучшений (всего 18, многие
   складываются: скорострельность, мультизалп, пробитие, рикошет, разрывные заряды, щиты,
   ракеты, рывок-таран, магнит, корпус, ремонт реактора, замедляющее поле, криты и др.).
4. На волнах 5, 10, 15 и 20 приходит босс с предупреждаемыми атаками (кольца пуль, рывок,
   призыв, спираль, телепорт). Победи босса 20-й волны — кампания пройдена.
5. Очки умножаются на комбо-множитель: он растёт с каждым убийством и тает, если
   не убивать. Режим **Бесконечный** открывается, когда ты впервые дошёл до 10-й волны;
   твои пять лучших забегов хранятся в таблице. «Продолжить» возобновляет забег с начала
   следующей волны.

## Управление

| действие | клавиатура / мышь | геймпад | касания |
|---|---|---|---|
| движение | WASD | левый стик / крестовина | левая половина экрана: стик |
| прицел | мышь (или стрелки) | правый стик | правая половина экрана: стик |
| огонь | левая кнопка мыши (зажать); стрелки | правый стик / RT | правый стик (авто) |
| рывок (неуязвимость на миг) | Пробел / Shift | RB / LB / A | кнопка «РЫВОК» справа внизу |
| пауза | Esc | Start | кнопка «II» |
| меню и карточки | мышь, стрелки + Enter, цифры 1–3 | D-pad / стик + A | касание |

Экранные стики появляются только после первого касания экрана.

## Запуск

```bash
cargo run -p swarm                       # играть
cargo test -p swarm                      # тесты без окна
python games/swarm/tools/gen_assets.py   # пересоздать графику (Pillow, numpy)
```

Отладочные переменные окружения (только десктоп): `SWARM_SCREEN=menu|mode|options|wave7|wave10_pause|wave5_upgrade|wave12_win|wave12_lose`
(стартовый экран; `waveN` — забег с автопилотом), `SWARM_STRESS=1` — нагрузочный режим
(400 врагов и 600 пуль), `SWARM_BOT=1` — автопилот. Скриншот без окна:

```bash
SWARM_SCREEN=wave7 ENGINE_FRAMES=900 ENGINE_SCREENSHOT=shot.png cargo run -p swarm
```

## Экспорт

```bash
cargo run -p piska-export -- web --game swarm --release        # браузер → dist/swarm/web
cargo run -p piska-export -- windows --game swarm --release    # Windows → dist/swarm/windows
cargo run -p piska-export -- serve dist/swarm/web --open       # проверить в браузере
```

В браузере геймпады пока не работают (ограничение движка), мышь и клавиатура — да.

## Устройство

* `src/sim.rs`, `boss.rs`, `data.rs`, `grid.rs` — вся логика без сцены: враги, пули и обломки лежат
  в пулах фиксированной ёмкости, столкновения «круг против круга» идут через равномерную сетку.
* `src/view.rs` — спрайты из одного атласа (пулы объектов), частицы, следы, числа урона.
* `src/ui.rs`, `flow.rs` — интерфейс на `engine-ui` и ход игры; `sound.rs` — звук из синтезатора.
* `src/bot.rs` — бот-игрок для тестов и автопилота.
* `tools/gen_assets.py` — рисует атлас, арену, фон, иконки и пишет `src/atlas.rs`, `.meta` и сцену.
