# Шаровой завод

3D-игра на Piska Engine. Вы катите стальной шар по цехам заброшенного завода, который
висит в небе над морем облаков: рампы, конвейеры, вращающиеся «метлы», вентиляторы, прессы,
хрупкие плиты, качели и ящики, которые надо толкать. Цель каждого цеха — добраться до
площадки отгрузки (зелёный круг). Упали — вернётесь на последнюю контрольную точку.

Игра — образец проекта «ассеты + скрипты»: **всё содержимое лежит в файлах** (сцены, префабы,
интерфейс, материалы, модели, звуки, данные, настройки), а код — это скрипты-компоненты на
Rust, по одному в файле (`src/scripts/`). Ничего не строится из кода: `build()` подключает
ассеты и загружает сцену меню.

**Платформы:** Windows, Linux, Android и **браузер (wasm32)**. Игра целиком на Rust, фича
движка `cpp` выключена, поэтому `tools/check-wasm.sh` её проверяет, а
`cargo check -p marble --target wasm32-unknown-unknown` проходит.

## Правила

1. Катите шар к площадке отгрузки; шестерёнки собирать необязательно, но в каждом цехе их
   13–27 и ещё одна **золотая**, спрятанная там, куда нужно постараться добраться.
2. Падение за край цеха (или раздавливание прессом) возвращает шар на последнюю контрольную
   точку; время при этом не останавливается, падения считаются.
3. Каждый цех ограничен по времени («смена»): не успели — «Смена окончена», цех провален.
4. За время — медаль: бронза, серебро, золото. Медали, рекорды, шестерёнки и золотые
   шестерёнки сохраняются.
5. Финиш цеха открывает следующий. Всего восемь цехов; последний — «Главный цех» — смешивает
   все механизмы.

## Управление

| | клавиатура и мышь | геймпад |
|---|---|---|
| катить | WASD или стрелки | левый стик, крестовина |
| прыжок | Пробел | A (South) |
| камера | правая кнопка мыши + движение, колесо — дальность, Q / E — поворот | правый стик |
| вернуться на контрольную точку | R | Y (North) |
| пауза | Esc | Start |
| меню | мышь, стрелки / Tab, Enter, Esc — назад | крестовина, A, B (East) — назад |

## Цеха

| № | название | что нового |
|---|---|---|
| 1 | Первая смена | кататься, прыгать через щель, ездить на платформе |
| 2 | Конвейерная | ленты по ходу, против хода и поперёк дорожки |
| 3 | Метлы | вращающиеся и качающиеся перекладины |
| 4 | Вентиляция | вентиляторы-лифты, боковой ветер, прыжок на струе |
| 5 | Прессы | поршни с ритмом, пресс над лентой |
| 6 | Хрупкий мост | плиты, что рассыпаются; качели; тяжёлые ящики |
| 7 | Ускорение | разгонные плиты, бамперы, длинные прыжки |
| 8 | Главный цех | всё сразу |

## Структура проекта

| путь | что там |

| `assets/scenes/courses/course_N.scene` | восемь цехов — настоящие объекты (иерархия, не код) |
| `assets/prefabs/track/` | блоки дорожки, рельсы, ящики, лампы, декор |
| `assets/prefabs/mech/` | механизмы: платформа, лента, метла, вентилятор, пресс, плита, бамперы… |
| `assets/prefabs/rig/` | камера, солнце, атмосфера, менеджер игры |
| `assets/prefabs/ball.prefab`, `pickups/` | шар, шестерёнки, контрольные точки, финиш |
| `assets/ui/` | экраны интерфейса как префабы: меню, выбор цеха, настройки, HUD, пауза, результаты, затемнение |
| `assets/materials/` | `.material` (настил, полосы, металл, ящик, лампы…) |
| `assets/models/` | `.obj`-модели: шестерня, зубчатое колесо, ротор вентилятора |
| `assets/textures/` | текстуры (`tools/gen_assets.py`) |
| `assets/audio/` | звуки и музыка (`.wav`, синтезированы один раз) |
| `assets/data/` | `courses.ron` (названия, медали), `sounds.ron`, `routes/` (маршруты для ботов) |
| `assets/project.settings` | окно, гравитация, теги и слои, карта ввода |
| `src/scripts/` | компоненты: `moving_platform.rs`, `sweeper.rs`, `conveyor.rs`, `fan.rs`, `crusher.rs`, `collapsing_tile.rs`, `booster.rs`, `bumper.rs`, `gear_pickup.rs`, `checkpoint.rs`, `finish_pad.rs`, `ball.rs`, `camera_rig.rs`, `game_manager.rs`… |
| `src/game/` | ядро без объектов: состояние, поток экранов, интерфейс, звук, чтение данных |
| `src/bin/marble-editor.rs` | редактор с зарегистрированными скриптами игры |
| `cpp/` | необязательный пример: один C++-компонент (фича `cpp-example`) |
| `tools/bake/`, `examples/bake_assets.rs` | инструмент, который однажды собрал сцены и префабы и умеет собрать заново |
| `tests/` | тесты без окна: механизмы, цеха, поток игры, бот, плавность, редактор |

## Открыть в редакторе

```bash
cargo run -p marble --features editor --bin marble-editor
```

Откройте `scenes/courses/course_1.scene` или любой префаб из `prefabs/`: иерархия, инспектор и
сцена работают как у обычного проекта. Правки сохраняются в файлы, игра подхватит их при запуске.

## Как добавить своё

* **Цех:** скопируйте `course_N.scene`, переставьте блоки и механизмы (перетащите префабы из
  `prefabs/track` и `prefabs/mech`), поставьте шар, финиш и контрольные точки; добавьте строку
  в `assets/data/courses.ron` (название, медали) и маршрут `data/routes/` (нужен только ботам).
* **Механизм (врага):** создайте скрипт (Assets → New Rust Script) в `src/scripts/`, соберите
  префаб из объекта с этим компонентом и поставьте его в сцену.
* **Экран интерфейса:** соберите канвас в редакторе, сохраните префаб в `assets/ui/` и
  поставьте его в сцену; кнопки шлют действия по имени (`src/game/ui.rs`).
* **Модель, материал, звук:** положите файл в `assets/models`, `assets/materials`, `assets/audio`.

## Что всё-таки создаётся из кода

Шар-пробник и объекты опытов в тестах; текстовые подписи интерфейса, которые игра обновляет
каждый кадр (время, шестерёнки); звук качения. Сцены, префабы, интерфейс, материалы и данные
из кода не создаются.

## C++

Один маленький необязательный пример: `cpp/CppSpinner.cpp`, фича `cpp-example`
(`cargo test -p marble --features cpp-example --test cpp_example`). По умолчанию фича выключена.
Помощник `crates/engine-cpp-build` и раздел «C++ в своей игре» в `docs/api/cpp.md` остаются.

## Запуск

```bash
cargo run -p marble                       # играть
ENGINE_FRAMES=600 cargo run -p marble     # бенчмарк: средний FPS пишется при выходе
cargo test -p marble                      # тесты без окна (ENGINE_AUDIO=off ставят сами)
```

Для проверки внешнего вида без окна есть переключатели окружения (картинка пишется
командой `ENGINE_SCREENSHOT=out.png ENGINE_FRAMES=90 cargo run -p marble`):

* `MARBLE_SCREEN` — `menu`, `select`, `options`, `c1`…`c8` (цех), `pause`, `results`, `lose`;
* `MARBLE_AT` — доля маршрута (0…1), куда поставить шар в цехе;
* `MARBLE_DEMO=1` — примерный прогресс для экрана выбора цеха.

## Ассеты

Текстуры (настил, предупреждающие полосы, шлифованный металл, ящик) рисует
`tools/gen_assets.py` (Python, Pillow и numpy): `python tools/gen_assets.py` из каталога игры.
Звуки и музыка — `.wav` в `assets/audio` (синтезированы инструментом `tools/bake`).

## Экспорт

```bash
cargo run -p piska-export -- windows --game marble --release
```

Linux и Android — командами `piska-export` соответствующих платформ (для веба — `tools/check-wasm.sh`).
Проверка Android без сборки APK: `cargo ndk -t arm64-v8a check -p marble`.
