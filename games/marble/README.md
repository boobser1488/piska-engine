# Шаровой завод

3D-игра на Piska Engine. Вы катите стальной шар по цехам заброшенного завода, который
висит в небе над морем облаков: рампы, конвейеры, вращающиеся «метлы», вентиляторы, прессы,
хрупкие плиты, качели и ящики, которые надо толкать. Цель каждого цеха — добраться до
площадки отгрузки (зелёный круг). Упали — вернётесь на последнюю контрольную точку.

Игра — витрина для **3D-физики** (Rapier: настоящие динамические тела, суставы, лучи,
силовые поля) и для **игровой логики на C++**: ядро (шар, камера, меню, правила) написано на
Rust, а все механизмы цехов — 14 компонентов на C++ в `cpp/`, которые линкуются в крейт
статически (`crates/engine-cpp-build`, см. `docs/api/cpp.md`, раздел «C++ в своей игре»).

**Платформы:** Windows, Linux, Android. **В браузер игра не собирается**: C++ не собирается
под `wasm32` (`docs/api/export.md`, раздел 7), поэтому `tools/check-wasm.sh` для неё не
применяется (на `wasm32` `build.rs` ничего не компилирует, а запуск вернёт понятную ошибку).

## Правила

1. Катите шар к площадке отгрузки; шестерёнки собирать необязательно, но в каждом цехе их
   13–27 и ещё одна **золотая**, спрятанная там, куда нужно постараться добраться.
2. Падение за край цеха (или раздавливание прессом) возвращает шар на последнюю контрольную
   точку; время при этом не останавливается, падения считаются.
3. Каждый цех ограничен по времени («смена»): не успели — «Смена окончена», цех провален.
4. За время — медаль: бронза, серебро, золото. Медали, рекорды, шестерёнки и золотые
   шестерёнки сохраняются.
5. Финиш цеха открывает следующий. Всего восемь цехов; последний — «Главный цех» — смешивает
   все механизмы.

## Управление

| | клавиатура и мышь | геймпад |
|---|---|---|
| катить | WASD или стрелки | левый стик, крестовина |
| прыжок | Пробел | A (South) |
| камера | правая кнопка мыши + движение, колесо — дальность, Q / E — поворот | правый стик |
| вернуться на контрольную точку | R | Y (North) |
| пауза | Esc | Start |
| меню | мышь, стрелки / Tab, Enter, Esc — назад | крестовина, A, B (East) — назад |

## Цеха

| № | название | что нового |
|---|---|---|
| 1 | Первая смена | кататься, прыгать через щель, ездить на платформе |
| 2 | Конвейерная | ленты по ходу, против хода и поперёк дорожки |
| 3 | Метлы | вращающиеся и качающиеся перекладины |
| 4 | Вентиляция | вентиляторы-лифты, боковой ветер, прыжок на струе |
| 5 | Прессы | поршни с ритмом, пресс над лентой |
| 6 | Хрупкий мост | плиты, что рассыпаются; качели; тяжёлые ящики |
| 7 | Ускорение | разгонные плиты, бамперы, длинные прыжки |
| 8 | Главный цех | всё сразу |

## Механизмы на C++ (`cpp/`)

`MovingPlatform`, `Sweeper` и `SweeperArm`, `Conveyor`, `Fan`, `Bumper`, `Crusher`,
`CollapsingTile`, `GearPickup`, `Checkpoint`, `Booster`, `FinishPad`, `Blinker`, `Cog`.
У каждого поля, видимые в инспекторе (`ENGINE_FIELD`). Они двигают объекты, пускают лучи и
пересечения сфер, прикладывают силы и импульсы к телам, играют звук, ставят твины и шлют
сообщения Rust-стороне (`"checkpoint"`, `"gear"`, `"golden_gear"`, `"finish"`, `"squashed"`,
`"shake"`). Rust строит цеха кодом (`src/kit.rs`, `src/courses.rs`) и создаёт C++-компоненты
по имени через реестр типов.

## Запуск

```bash
cargo run -p marble                       # играть
ENGINE_FRAMES=600 cargo run -p marble     # бенчмарк: средний FPS пишется при выходе
cargo test -p marble                      # тесты без окна (ENGINE_AUDIO=off ставят сами)
```

Для проверки внешнего вида без окна есть переключатели окружения (картинка пишется
командой `ENGINE_SCREENSHOT=out.png ENGINE_FRAMES=90 cargo run -p marble`):

* `MARBLE_SCREEN` — `menu`, `select`, `options`, `c1`…`c8` (цех), `pause`, `results`, `lose`;
* `MARBLE_AT` — доля маршрута (0…1), куда поставить шар в цехе;
* `MARBLE_DEMO=1` — примерный прогресс для экрана выбора цеха.

## Ассеты

Текстуры (настил, предупреждающие полосы, шлифованный металл, ящик) рисует
`tools/gen_assets.py` (Python, Pillow и numpy): `python tools/gen_assets.py` из каталога игры.
Звук и музыка синтезируются из кода (`src/sounds.rs`), файлов нет.

## Экспорт

```bash
cargo run -p piska-export -- windows --game marble --release
```

Linux и Android — командами `piska-export` соответствующих платформ (C++ собирается
`cc`-ом нужного компилятора: MSVC, GCC/Clang, clang из Android NDK).
Проверка Android без сборки APK: `cargo ndk -t arm64-v8a check -p marble`.
