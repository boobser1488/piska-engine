# Ташбазар

Контроллер от первого лица с классической физикой движения (`engine::fps::FpsController`,
руководство — `docs/api/fps.md`) и карта для него: **Ташбазар** — пустынный городок на две
точки задания для командной игры «пять на пять». Своя раскладка: две стороны (атакующие с
севера, защитники с юга), середина по сухому каналу, два фланга, узкие проходы, крытый базар,
акведук над красильным двором. Оружия, врагов и ботов-противников нет — только движение и
карта. В игре три режима: **прогулка** по карте, **полоса препятствий** на время (крыши,
прыжки со стрейфом и с приседом) и **полигон** с эталонными размерами.

```text
cargo run -p tashbazar                                   # игра (меню → «Прогулка по карте»)
TASHBAZAR_SCENE=gym cargo run -p tashbazar               # сразу полигон
cargo run -p tashbazar --features editor --bin tashbazar-editor   # проект в редакторе
cargo run -p tashbazar --example bake_assets             # перегенерировать ассеты
```

## Управление

| | |
|---|---|
| мышь | взгляд (курсор захвачен; Esc — пауза и курсор свободен) |
| W A S D | бег (250 ед/с = 4.76 м/с) |
| пробел или колесо мыши | прыжок (повторный — только новым нажатием; «Автопрыжок» в настройках) |
| Ctrl (или C) | присед; в прыжке — прыжок с приседом (+18 ед высоты) |
| Shift | шаг (тихо, 52 % скорости) |
| R | назад на точку появления / на последнюю отметку полосы |
| V | полёт сквозь стены (отладка) |
| Esc | пауза: продолжить, начать заново, настройки, в меню, выход |
| геймпад | левый стик — ход, правый — взгляд, South — прыжок, East — присед, Start — пауза |

**Настройки** (сохраняются сразу): чувствительность мыши (как в классике: градусы = отсчёты ×
чувствительность × 0.022), угол обзора (горизонтальный на 4:3; на 16:9 шире), громкость,
автопрыжок, спидометр, инверсия мыши.

**Как прыгать по-классически.** Скорость в воздухе растёт только поперёк движения: в прыжке
отпустите W, держите A или D и плавно ведите мышь в ту же сторону — «стрейф». Прыжок в тот же
миг, что коснулись земли, не теряет скорость — «распрыжка». Присед в прыжке подтягивает ноги:
так берутся ящики 1.25 м (обычный прыжок — до 1.09 м).

Сверху вниз: Караванные ворота (`a`) с Канатной улицей на запад и Пряным рядом на восток;
слева — Длинная стена, ведущая на A через Арку; в середине — канал от спавна атакующих к Двору
колодца (`d`) с мостом и спусками посередине; справа — Крытый базар и Тёмный проход на Б;
между Длинной стеной и каналом — Красильный двор под акведуком и Фонарный переулок к Коротким
воротам A; внизу — Оливковая улица (к A) и Гранатовый сад (к Б) от спавна защитников.

Вид сверху — кадр `13_plan` теста `shots` (ниже); точные размеры — в `tools/bake/map.rs`
(улицы и дворы заданы прямоугольниками, остальное застраивается домами автоматически).

**Районы и позывные** (их пишет HUD): Караванные ворота (спавн атакующих), Канатная улица,
Длинная стена (прямая 46 м — главная дальняя линия), Красильный проход и двор (под акведуком,
чаны — укрытия), Обрыв над каналом (окно в середину), Фонарный переулок, Западный и
Восточный спуск (лестницы из канала), Верблюжий мост, Сухой канал (середина, 1.5 м ниже улиц),
Короткие ворота и Арка (входы на A), **Цистерна — площадка A** (платформа 1.25 м с баком,
водонапорная башня), Пряный ряд и Крытый базар (под навесами, лотки), Тёмный проход (с изломом),
**Караван-сарай — площадка Б** (галерея-балкон, аркада, бассейн), Задний переулок,
Двор колодца (спавн защитников), Оливковая улица, Гранатовый сад, Садовые ворота.

**Маршруты и время бегом** (250 ед/с; «по плану» — длина пути / скорость + 5 %, «бот» —
прогон бота контроллером, тест `routes`; допуск ±15 %):

| маршрут | длина | по плану | бот |
|---|---|---|---|
| атакующие → A: Канатная улица, Длинная стена, Арка | 104 м | 22.9 с | 21.9 с |
| атакующие → A: канал, Западный спуск, Фонарный переулок, Короткие ворота | 88 м | 19.3 с | 18.5 с |
| атакующие → Б: Пряный ряд, Крытый базар, Тёмный проход | 110 м | 24.1 с | 23.0 с |
| атакующие → Б: канал, Восточный спуск, Задний переулок | 99 м | 21.8 с | 20.9 с |
| атакующие → середина (под мостом) | 44 м | 9.7 с | 9.3 с |
| защитники → A: Оливковая улица, Оливковые ворота | 65 м | 14.3 с | 13.7 с |
| защитники → Б: Гранатовый сад, Садовые ворота | 61 м | 13.4 с | 12.8 с |
| защитники → середина (под мостом) | 51 м | 11.2 с | 10.7 с |

Защитники приходят на точки за 13–14 с, атакующие — за 19–24 с; в середине стороны
встречаются почти одновременно (≈10 и ≈11 с).

**Укрытия и меры** (под корпус контроллера 1.37 м, см. `docs/api/fps.md`): ящики 0.9 м
(запрыгнуть), 1.25 м (только с приседом), стопки по 1.8 м (в рост); бочки 0.9 м; бортик
бассейна 0.6 м; парапеты 0.7–1.0 м; двери 2.2 м; ступени 0.25 м; пандусы канала 14°.

**Полоса препятствий** (кнопка в меню; секундомер — с момента, как сошли со старта; лучшее
время сохраняется): ящики 0.9 / 1.8 / 2.7 м → прыжок с приседом на крышу сторожки (3.95 м) →
прыжок через переулок 3.5 м на крышу дома у канала → акведук → **пролом 4.35 м: только прыжок
со стрейфом** → водонапорная башня (прыжок с приседом с акведука) → вниз на площадку A →
прыжок с приседом на платформу цистерны (финиш). Упали с крыш — назад на последнюю отметку.
Бот проходит её за 19.3 с.

## Править карту в редакторе

`cargo run -p tashbazar --features editor --bin tashbazar-editor` (или из хаба), открыть
`scenes/tashbazar.scene`. В иерархии карта разложена по группам: **Ground** (мостовая, канал,
пандусы, лестницы), **Buildings** (дома — блоки), **Camel Bridge**, **Aqueduct**, **Site A —
Cistern**, **Site B — Caravanserai**, **Spice Market**, **Covered Souk**, **Dye Yard**,
**Caravan Gate — Attackers**, **Well Court — Defenders**, **Streets** (укрытия), **Zones**
(позывные HUD), **Movement Course** (отметки).

* **Стена / пол / крыша** — экземпляр `prefabs/blocks/<материал>.prefab`: двигайте и тяните
  масштабом — коллайдер тянется вместе с ним, текстура не растягивается. Новая стена —
  перетащите блок из Project в сцену. Сменить материал — перетащите `.material` на объект или
  поменяйте префаб в `blocks/`.
* **Укрытие** — `prefabs/props/crate_small` (0.9 м), `crate_big` (1.25 м), `crate_long`,
  `barrel`, `cart`. Корень каждого предмета — в его основании: поставленный на y пола, он
  стоит на полу. Корень окна, двери, настенного фонаря и навеса — на плоскости стены, +Z
  смотрит наружу.
* **Окно** — `prefabs/facade/window` (ставни распахнуты), `window_shut` (закрыты: две
  створки с жалюзи в проёме, петли), `window_half` (одна створка открыта), `window_ajar`
  (приоткрыты), `window_blind` (заложено) — у всех тот же проём 0.8 × 1.2 м, рама,
  подоконник и перемычка, что у открытого (проверяет `placement`). Закрыть
  окно — заменить префаб экземпляра на `window_shut`, а не двигать створки открытого: у
  него обе створки называются `Shutter`, и переопределение по пути попадает в первую.
* **Точка появления** — `prefabs/markers/spawn_attackers` / `spawn_defenders`; порядок — поле
  `index`, взгляд — ось −Z объекта (синяя стрелка гизмо).
* **Позывной** — `prefabs/markers/zone`: поле `title` и размер зоны `size`.
* **Полоса** — отметки `course/checkpoint` / `course/finish` под объектом *Movement Course*;
  их порядок — поле `checkpoints` у `MovementCourse` (перетащите объекты в список).
* Размеры, под которые построена карта, показывает полигон (`scenes/gym.scene`).

### Редактор и генератор

Карту правят **в редакторе**. Генератор (`cargo run -p tashbazar --example bake_assets`)
нужен, когда раскладка меняется в коде (`tools/bake/map.rs`), и правки из редактора он не
теряет:

* **Сцены не перезаписываются, а сливаются.** У каждого объекта, который ставит генератор,
  постоянный номер (`id` в файле). Что генератор записал в прошлый раз, лежит в
  `bake_state/<сцена>.baked.ron` (рядом с `assets/`, в игру не попадает). Объект, который
  в редакторе **не трогали**, обновляется до нового результата генератора; **правленный**
  (сдвинут, повёрнут, другой префаб, переопределения, выключен) остаётся как есть;
  **удалённый** в редакторе не возвращается; **добавленный** в редакторе остаётся. Объект,
  который генератор больше не ставит, уходит, только если его не трогали. Генератор
  печатает, что оставил («kept edited / deleted / added»).
* `-- --overwrite-scene` — записать сцены заново целиком; перед записью печатается каждая
  правка, которая пропадёт. Если записи `bake_state` нет, а сцена есть, генератор без этого
  флага отказывается писать сцену.
* Сцены пишутся атомарно (временный файл → переименование). Если сцена открыта в
  редакторе, после генератора её надо перезагрузить, а не сохранять поверх.
* **Что генератор перезаписывает:** текстуры, материалы, префабы, свои модели
  (`models/*.obj` — набор витрины, ящики, телега), интерфейс, звуки, `data/*.ron`,
  `project.settings` — их список в `bake_state/files.txt`. Из этого списка он удаляет только
  то, что сам перестал создавать. **Чего не трогает:** любые другие файлы в `assets/`
  (модели из Modeler — `*.pmodel`, свои префабы и материалы, если имя не совпадает с
  генерируемым), `.meta` (GUID не меняются, ссылки сцен остаются целы).
* Тест `cargo test -p tashbazar --test bake_merge` падает, если следующий запуск генератора
  потерял бы хоть одну правку в лежащих сейчас сценах.

## Настроить контроллер

Объект **Player** → компонент `FpsController`: все параметры в метрах с классическими
значениями по умолчанию (таблица — `docs/api/fps.md`). Быстрее разгон в воздухе (для сёрфа) —
`air_accelerate` 100; выше прыжок — `jump_height`; другой «тикрейт» — `Time → Fixed Timestep`
в настройках проекта (движение от него не зависит, только точность).

## Тесты

```text
cargo test -p tashbazar --test placement                  # ничего не висит, не тонет, не мерцает
cargo test -p tashbazar --test bake_merge                 # генератор не теряет правки из редактора
cargo test -p tashbazar --test routes                     # боты: 8 маршрутов + полоса
cargo test -p tashbazar --features editor --test assets   # сцены и префабы в редакторе
TASHBAZAR_SHOTS=<каталог> cargo test -p tashbazar --test shots -- --ignored --nocapture   # кадры и замер (GPU)
```

`placement` проверяет обе сцены и печатает таблицу нарушителей: предмет висит над опорой или
утоплен в неё больше чем на 1–3 см, деталь модели оторвана от остальных, корень не в основании,
две разные грани совпадают (мерцание), предмет входит в стену или в другой предмет, настенный
предмет не касается стены, на стене что-то перекрывается (фонарь на окне, навес на окне, окно
за углом стены, открытое окно за лотком, окно в стену соседа). `shots` дополнительно пишет листы моделей с четырёх сторон
(`models/`) и кадры с высоты глаз вдоль каждого маршрута и у каждого предмета (`walk/`);
с `TASHBAZAR_DEBUG_OFFENDERS=1` нарушители подкрашены красным.

Стиль — пиксель-арт: все текстуры по 16 текселей на метр (как у моделей Piska Modeler),
палитра из 36 цветов (`tools/bake/textures.rs`), фильтр `Pixel` (резко вблизи, мипмапы
вдали — не рябит); большие поверхности кладутся в мировых координатах, у ящиков и телеги —
свои пиксельные атласы по развёртке (`tools/bake/meshes.rs`).

Свои ассеты: текстуры нарисованы кодом, звуки синтезированы, модели — из набора витрины
движка (`assets/showcase`). Названия мест, раскладка и игра — свои.
